Progress is saved in this browser after every row. If the tab closes, re-open the page, upload the same CSV and press Start — finished rows are skipped. Download any time; unfinished rows are left blank.

What the output CSV contains

All your original columns, unchanged and in order, plus: serp_query, serp_status, serp_error, serp_fetched_at, result_count, r1_title … r10_title, r1_link … r10_link, r1_snippet … r10_snippet, answer_box, knowledge_graph, people_also_ask, related_searches, top_stories, raw_json (the full Serper response for that row). Google's AI Overview is not included — Serper does not return it.
