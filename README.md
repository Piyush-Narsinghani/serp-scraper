# Google First-Page Scraper

Upload a CSV, get Google's first page for every row via the [Serper](https://serper.dev) API, and download the results as a new CSV. Everything runs in your browser; your API key is sent only to google.serper.dev and is never stored in this repository.

**Use it:** https://piyush-narsinghani.github.io/serp-scraper/

Output = all original columns + top 10 results (title, link, snippet), answer box, knowledge graph, People also ask, related searches, top stories, and the raw Serper JSON per row. Google's AI Overview is not included (Serper does not return it).
